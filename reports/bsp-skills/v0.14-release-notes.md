# BSP skill v0.14

Единый скил `bsp` для применения 1С:БСП 3.1.11. Архивы содержат `skills/bsp/` и установщики `install.sh` / `install.ps1`; локальные документация и XML-выгрузка БСП в поставку не входят.

## Что изменилось

- Уточнена маршрутизация задач БСП: сообщения у реквизита формы и безопасная запись при обновлении отличены от обычного BSL и платформенной регистрации изменений.
- Для блокировки реквизитов формы и создания регламентных заданий приведены корректные конструкторы параметров BSL; добавлены предупреждения о несуществующих фабриках и вызовах.
- Scorer защищён регрессиями от выдуманных BSP-методов и некорректного `Новый Массив("...")`, при этом корректный BSL с эквивалентными проверками и предупреждениями о *другом* модуле не отклоняется.
- К исходному guided-корпусу добавлен отдельный корпус ненаводящих задач с отрицательными границами и проверкой поведения при запросе другой версии БСП.

## Проверки кандидата

- 109 unit-тестов; API coverage 664/664 по всем 24 references; семантическая сверка с локальной выгрузкой БСП 3.1.11 — 0 ошибок, 0 предупреждений.
- Полный guided RED/GREEN, 27 сценариев × 3 повтора: GREEN **27/27 по большинству**, 77/81 отдельных ответов, gate PASS.
- Отдельный корпус активации, 6 сценариев × 3 повтора: GREEN **6/6 по большинству**, 16/18 отдельных ответов, gate PASS.
- Оба установщика проверены на установке и обновлении из локального распакованного архива; ZIP и tar.gz проверены побайтно.

**Ограничения:** PASS не означает безошибочность каждого ответа: зафиксированы единичные пропуски чтения reference/активации и неподтверждённый ответ о БСП 3.2.1. Скил и семантическая проверка API относятся к **БСП 3.1.11**; факты других версий не следует переносить без документации нужной версии. В поведенческом тесте не доказана полная изоляция host plugins. Сырые трассы и разбор — в [отчёте о кандидате](https://github.com/brake71/1c-ssl-skills/blob/v0.14/reports/bsp-skills/v0.14-release-candidate-readiness.md).

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/brake71/1c-ssl-skills/v0.14/install.sh | bash -s -- --ref v0.14
```

PowerShell (из распакованного архива): `./install.ps1 -Agent Codex -SourceDirectory .`. При установке из клона можно использовать `./install.ps1 -Agent Codex -Ref v0.14`.
