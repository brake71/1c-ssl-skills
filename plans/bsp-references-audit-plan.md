# План перепроверки всех reference-файлов скила bsp

Цель: систематически проверить все 24 reference-файла в
`.claude/skills/bsp/references/` на точность сигнатур, правильность описания
хуков, регионов, устаревших методов и примеров. Опорные источники —
`src/cf/` (исходный код БСП 3.1.11) и `bsp3111_md/` (документация БСП 3.1.11).

Дата старта: 2026-07-04.

## Методология проверки (для каждого reference)

Для каждого файла выполнить:

1. **Сигнатуры методов** — каждый метод, упомянутый в reference, проверить
   через `src/cf/CommonModules/<Модуль>/Ext/Module.bsl` (PowerShell:
   `Get-Content … | Select-String` — `grep_search` по `.bsl` не работает):
   - [ ] Имя метода существует в указанном модуле.
   - [ ] Количество и имена параметров совпадают.
   - [ ] Тип возвращаемого значения (Функция/Процедура) совпадает.
   - [ ] Суффикс `Экспорт` присутствует (если утверждается, что метод экспортный).
   - [ ] Альтернативные сигнатуры (перегрузки, служебные варианты) — описаны
     или помечены.

2. **Регионы методов** — для каждого метода проверить регион `#Область`:
   - [ ] `ПрограммныйИнтерфейс` — stable, можно вызывать из прикладного кода.
   - [ ] `СлужебныйПрограммныйИнтерфейс` / `СлужебныеПроцедурыИФункции` — ⚠️
     служебный, помечен в reference как таковой.
   - [ ] `УстаревшиеПроцедурыИФункции` — ⚠️ deprecated, помечен.
   - [ ] Хуки `*Переопределяемый` — описаны как «БСП вызывает, прикладной код
     реализует, не вызывается напрямую».

3. **Хуки переопределения** — для каждого `*Переопределяемый` модуля:
   - [ ] Сигнатуры хуков проверены по `src/cf/CommonModules/<Модуль>/Ext/Module.bsl`.
   - [ ] Указано, что хук реализует прикладной код, а не вызывает.
   - [ ] Устаревшие хуки помечены `❌ устарел`.

4. **Примеры кода** — каждый пример в reference:
   - [ ] Ссылается на реальный объект/модуль из `src/cf/` (не выдуманный).
   - [ ] Имена переменных/параметров совпадают с реальным кодом.
   - [ ] Отступы — табы, без длинного тире (—), русский синтаксис 1С.

5. **Антипаттерны** — каждый `❌`-пункт:
   - [ ] Описывает реальную ошибку, а не надуманную.
   - [ ] Не противоречит фактическому поведению БСП.

6. **Модули (заголовок reference)** — список модулей с их суффиксами:
   - [ ] Модули существуют в `src/cf/CommonModules/`.
   - [ ] Суффиксы (`*Клиент`, `*ВызовСервера`, `*Переопределяемый`, `*Служебный`)
     корректны.
   - [ ] Служебные модули помечены `⚠️ служебный`.

7. **Перекрёстные ссылки** между reference-файлами:
   - [ ] Имена файлов-ссылок существуют в `references/`.
   - [ ] Нет зеркальных ссылок на `bsp321_md/`.
